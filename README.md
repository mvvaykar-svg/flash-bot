# AI Bro

I built this on my 15th birthday - 13th November.

I wanted to understand how apps like ChatGPT actually work. So instead of just using them, I decided to build one myself.

### What it does

- Chat with AI using OpenAI GPT-OSS 20B
- Upload a PDF and ask questions from it
- Streams answers live, like a real chatbot
- Remembers the conversation

### Tech Used

Python, Streamlit, Groq API, PyPDF2

### How to run

```bash
pip install -r requirements.txt
streamlit run app.py
